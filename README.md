\# ReqRes API Testing Project



\## Project Overview

This project demonstrates API testing using Postman and the ReqRes REST API.



The project focuses on validating API functionality, response status codes, response bodies, data types, and error handling through JavaScript assertions.



\## Tools \& Technologies

\- Postman

\- JavaScript

\- REST API

\- JSON

\- Git \& GitHub



\## API Under Test

ReqRes API: https://reqres.in/



\## Test Coverage



The collection contains 15 API requests covering:



| HTTP Method | Functionality | Number of Requests |

|---|---|---:|

| GET | Users | 3 |

| POST | Create User | 1 |

| PUT | Update User | 1 |

| PATCH | Partial Update User | 1 |

| DELETE | Delete User | 1 |

| GET | Delayed Response | 1 |

| GET | Resources | 3 |

| POST | Register | 2 |

| POST | Login | 2 |

| \*\*Total\*\* | | \*\*15\*\* |

1\. Download or clone this repository.

2\. Open Postman.

4\. Open the collection.

5\. Execute individual requests or run the entire collection.
